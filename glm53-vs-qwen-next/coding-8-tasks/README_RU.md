# GLM-5.3-Flash: точный повтор восьми coding-agent задач

[Все восемь вопросов, без ответов](TASKS_ONLY_RU.md) · [Статья о Qwen FP8/AWQ/27B](../../flash-next-awq-vs-fp8/README_RU.md) · [Статья о GLM](../README_RU.md)

Этот набор состоит из восьми исходных кратких формулировок, опубликованных в статье о трёх Qwen. Формулировки скопированы до эталонных решений; новые требования внутрь задач не добавлены.

**Протокол прохождения:**

1. Запиши точное название checkpoint GLM, vLLM build, MTP и настройки GPU. Сохрани их неизменными в ходе восьми задач.
2. Открывай **новый чистый диалог** для каждой отдельной задачи: `task_01.md` → `task_08.md`. Не отправляй модели весь файл `TASKS_ONLY_RU.md` сразу. Восемь заданий в одном контексте не являются тем же экспериментом.
3. Не показывай модели эталонные решения, старые работы Qwen, оценки и архивы предыдущих попыток. Рабочая директория агента должна быть отдельной.
4. Дай модели обычные инструменты программирования и тестирования. Попроси выполнить тесты реально, сохраняя их фактический вывод. Если PostgreSQL или TypeScript отсутствуют, отметь ограничения.
5. Для каждой сессии сохрани ZIP истории, итоговые файлы, результаты тестов и код (скорость и время здесь не оцениваются).
6. По итогам восьми сессий проведём независимую оценку по прежней шкале 0–10, добавим GLM в таблицу оригинальной статьи по правильности и отметим, чем различались условия.

**Методическое ограничение:** статья на GitHub содержит сокращённые текстовые условия, но не дословную стенограмму всех первоначальных запросов. Настоящий набор строго сохраняет именно опубликованные формулировки, а не реконструирует отсутствующие детали.
